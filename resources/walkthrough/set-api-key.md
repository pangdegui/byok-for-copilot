# Set your API Key

BYOK requires API endpoints to be configured before you can use it in Copilot Chat.

## Configure an Endpoint

1. Open the **BYOK** view in the Activity Bar
2. Click **Add Endpoint** (+)
3. Fill in:
   - **Endpoint name** — a friendly name (e.g., `my-provider`)
   - **API URL** — the base URL of your API provider
   - **Protocol** — OpenAI-compatible or Anthropic-compatible
   - **Models** — comma-separated model IDs

4. Click on the endpoint and set your **API Key**

> 💡 You can also configure endpoints directly in your VS Code settings under `byok-copilot.endpoints`.
