# Show BYOK models

After configuring an endpoint with an API key, BYOK models should appear in the Copilot Chat model picker.

## If models are hidden

1. Open the Copilot Chat model picker
2. Click **Manage Models** (or run `Developer: Manage Language Models`)
3. Look for **BYOK** models in the list
4. Make sure they are **shown** (not hidden)

> 💡 BYOK models are named like `byok-v4-flash@my-endpoint` and `byok-v4-pro@my-endpoint`.
