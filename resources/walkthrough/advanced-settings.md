# Advanced Settings

## Custom Model ID Overrides

If your API provider uses different model names, you can override them in settings:

- `byok-copilot.modelIdOverrides` — map VS Code model IDs to provider-specific IDs

## Vision Proxy

Configure a vision-capable model to describe images:

1. Run `BYOK: Configure Vision Proxy`
2. Choose a VS Code language model or an API endpoint

## Experimental Features

- **Stabilize Tool List** — may improve context-cache hit rate when tools change across conversation turns
